# Schema's van Geensnor

Tot nu toe alleen het schema voor de Hotspots.

## Voorbeelden

Alle voorbeelden in de map voorbeelden kunnen gevalideerd worden met de schema's. Mogelijk moet je in VS code nog even het onderstaande stuk configuratie toevoegen zodat de domeinen van de externe schema's worden vertrouwd

```json
{
  "json.schemaDownload.trustedDomains": {
    "https://geojson.org/": true
  }
}
```
